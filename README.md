# BopVisualEffects

BepInEx 5.x mod for Bits & Bops that adds additional visual effects for the in-game editor.

## Project layout

- `BopVisualEffects/BopVisualEffectsPlugin.cs`: Main plugin entrypoint (`BaseUnityPlugin`).
- `MyPluginInfo` is auto-generated by `BepInEx.PluginInfoProps` from metadata in `BopVisualEffects/BopVisualEffects.csproj`.
- `BopVisualEffects/Features`: Feature implementation files.
- `BopVisualEffects/Patches`: Harmony patches.
- `BopVisualEffects/Services`: Shared services/helpers.
- `BopVisualEffects/GameDependencies.props`: Names of game-managed DLLs to reference (without `.dll`).
- `BopVisualEffects/BopVisualEffects.user.props.example`: Local machine path template.

## Local setup

1. Copy `BopVisualEffects/BopVisualEffects.user.props.example` to `BopVisualEffects/BopVisualEffects.user.props`.
2. Set `GameRoot` in `BopVisualEffects/BopVisualEffects.user.props` to the path where Bits & Bops is installed.
3. Build the solution with `dotnet build BopVisualEffects.sln`

Derived paths:
- `BepInExPluginsDir = <GameRoot>/BepInEx/plugins`
- `UnityManagedDir = <GameRoot>/Bits & Bops_Data/Managed`

If `BepInExPluginsDir` exists, build output is copied there automatically.
